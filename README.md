# Construction-app

AI drill for a construction application focused on tracking and monitoring the construction lifecycle of residential products.

## Scope

- Track residential construction products from planning to completion.
- Monitor execution status, milestones, delays, and blockers.
- Highlight risk signals using AI-assisted monitoring insights.

## Core Monitoring Data

- Product/unit identification (lot, block, model).
- Phase progress (foundation, structure, finishing, delivery).
- Timeline health (planned vs. actual dates).
- Quality and issue tracking with resolution status.
